👋 자기소개

저는 대규모 데이터 시스템을 구축해 온 약 9년 경력의 데이터 엔지니어입니다.

이전에는 네이버에서 여러 서비스에 걸쳐 일간 활성 사용자(DAU) 2천만 명 이상을 지원하는 데이터 플랫폼을 구축했습니다.

이벤트 기반 데이터 시스템과 레이크하우스 아키텍처를 설계해, 대규모 이벤트 데이터를 AI와 비즈니스에 바로 쓰일 수 있는 신뢰할 수 있는 분석용 데이터셋으로 만드는 일에 집중하고 있습니다.

인프라만이 아니라 데이터가 실제로 어떻게 활용되는지에도 깊이 관심을 두고, 파생 데이터셋을 만들고 지표를 정의하며, 셀프 서브 분석과 대시보드로 팀이 스스로 분석할 수 있도록 돕는 일을 중요하게 생각합니다.

캐나다로 이주한 이후에는 개인 프로젝트에서 비정형 데이터를 구조화해 활용 가능한 형태로 바꾸는 LLM 기반 데이터 시스템을 다루고 있습니다.

데이터 플랫폼, 분석, AI 시스템에 관한 대화는 언제든 환영합니다.
